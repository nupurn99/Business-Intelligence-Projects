# Salespoint E-Commerce Dashboard

An interactive **Power BI dashboard** for analyzing e-commerce sales, quantity, profit, payment methods, product categories, and regional performance.

Dashboard link: https://app.powerbi.com/groups/me/reports/57d4d803-b333-426b-b61c-3f9e9ac9191d/ReportSection?experience=power-bi

## Key Insights

- Sales and profit performance
- Sales distribution by state
- Quantity by product category
- Profit by sub-category
- Payment method distribution
- Monthly sales and profit trends
- Quarterly and state-level filtering

## Technologies Used

- **Power BI** — Dashboard development and visualization
- **Power Query** — Data cleaning and transformation
- **DAX** — Calculated measures and analytical metrics
